# Owner Review Governance

Owner-review packets are decision aids, not automatic approvals.

Required sequence:

1. Designer review.
2. Owner disposition.
3. Controlled import to `legacy-recovery`.
4. Schema, reference, Pack, and smoke validation.
5. Rollback verification.
6. Source-closure certification.
7. Separate explicit Main Canon merge decision.

No generated artifact authorizes an automatic Main Canon write.
