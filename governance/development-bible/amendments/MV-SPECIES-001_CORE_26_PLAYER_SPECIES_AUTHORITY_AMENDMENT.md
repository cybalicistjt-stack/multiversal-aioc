**Status:** normative amendment pending consolidation

This amendment changes current player-species authority without rewriting sealed historical evidence.

1. The current core playable-species roster contains **26** species.
2. The historical 25-species roster remains valid as historical PPIA/CAPP completion evidence.
3. **Morganthyr** is the current canonical identity replacing legacy `Nekron` / `Nekrons` terminology. `Morganth` may be used as a singular form when context requires it.
4. **Akwi** is a core playable species. Existing AKWI-01 governed integration is reused; supplemental storage does not imply non-core status.
5. **Ratman** is one core playable species with the following recovered subordinate lineage/subspecies set: Rattori, Nybra, Rattakar, Ratborn, Chitta, Taipanua, Ska, Muridian, Raughtt.
6. Raughtt are established only as proper, aristocratic Ratmen of Dominix until further owner-authored material exists.
7. Future current-authority species/form, Character Builder, Appearance Studio, renderer-production, migration, catalog, and validation work must not treat 25 as the current complete roster.
8. Sealed completion reports and validators may retain historical 25-count and Nekron wording where necessary to reproduce exact prior evidence.
9. The old Evernote species formerly named Bougadahl is **The Jee**; current Bougadahl remains the later beetle species. Neither is added to the Core 26 by this amendment.
