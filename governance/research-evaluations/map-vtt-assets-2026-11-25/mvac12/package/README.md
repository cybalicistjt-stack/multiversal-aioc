# MVAC-12 evidence

Open `Multiversal_MVAC12_Storage_and_Map_Continuity.html` directly. It is the complete app prototype and requires no other file in this archive. See the validation report and JSON evidence for tested boundaries and open browser/device acceptance.

The source snapshot documents the split-store adapters, bounded drawing and maintenance integration. Tests use Node 24, @napi-rs/canvas and existing MVAC-07/11 intake contracts, fixture evidence and baseline HTMLs in the shared project workspace. This evidence ZIP is not an independent installation or a replacement media library. Database test files and transient run logs are excluded. SQLite is a local development adapter; the HTML uses its embedded IndexedDB adapter.
