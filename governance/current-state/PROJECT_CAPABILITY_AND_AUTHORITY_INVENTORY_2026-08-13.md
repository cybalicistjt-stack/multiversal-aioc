## 10. Current solidity defects

The dominant problem is not missing completed work; it is **projection drift and historical overlap**.

Observed examples:

- old AIOC `PROJECT_MEMORY.json` still selects 8E-009A;
- old AIOC current-state/session-handoff files still select 8D-007;
- old operational handoff still describes an obsolete canonical branch/next action;
- Internal Alpha backlog still contains a stale IA-D09 pending projection;
- app `.ai/next-task.md` and owner control center still emphasize WP-011 while newer app controls select A2;
- historical files in `.agent/active-work-orders/` can look live even when later evidence completed them;
- historical branches and open PRs preserve useful work but are not classified strongly enough for agents.

The current bootstrap v5.5.0 already mitigates this by prioritizing runtime pointer/checkpoint/branch/PR evidence over stale prose. The solidity program must now make the human-readable projections agree with that authority.
