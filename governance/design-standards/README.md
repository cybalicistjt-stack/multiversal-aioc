## Noncanonical artifacts

Legacy numbering files, superseded drafts, `From_Scratch` packages, working-package ZIPs, and duplicate recovery containers are evidence/history only. They must not compete with current standard IDs or be treated as canonical publications.

`STAGE-A-A2 — Universal Object Experience` remains the authorized current application item. The Design Standards subproject is a parallel owner-selected documentation/design-system operation. DS-012 supplies visual authority for A2; A2 supplies later functional/acceptance detail where it does not conflict with the approved standards.
