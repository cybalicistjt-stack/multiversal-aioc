# IA-D07-005 Integrated Journey Fixtures

Twenty-four deterministic fixtures exercise the eight integrated journeys across authoring, review, publication, Campaign installation, overlays, runtime reveal/advance, migration, disablement, historical replay, import/export, hidden-information filtering, accessibility, concurrency, and recovery.

Fixtures include canonical World entry publication; Adventure branch run; creator Item approval/install; local Creature override; accepted and rejected migrations; GM-only reveal; disabled definition runtime block; historical tombstone replay; import collision; role-filtered export; duplicate publish; stale install; lost-response lookup; Event-gap repair; compensating reversal; inaccessible graph fallback; hidden dependency non-inference; Campaign divergence; pack removal; provenance replay; AI publication refusal; canonical-promotion refusal; and full end-to-end author-to-session flow.

Each fixture declares initial versions, actors, authority dimensions, request, validation, authoritative result group, Events, projections, provenance, and recovery.
