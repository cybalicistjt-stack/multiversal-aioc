# MAS Benchmark Capability Matrix

**Program:** MAS — Multiversal Adventure Studio  
**Checked:** 2026-09-11  
**Purpose:** clean-room capability benchmark only  
**Implementation authority:** none

## Rule

MAS studies public documentation and ordinary user-visible workflows. It does not copy proprietary source, protected content/assets, sample projects, distinctive UI expression, private protocols or vendor-specific implementation details.

## Benchmark set

- Foundry Virtual Tabletop: portable Adventure documents, linked Scenes, Actors, Items, Journals, tables, cards and playlists.
- World Anvil: linked world notes, plots, sessions, NPCs, quests, timelines, preparation and storyteller-screen workflows.
- LegendKeeper: wiki authoring, map links, boards, secrets, templates, search, offline access, timelines and calendars.
- Alchemy RPG: scene preparation, hidden notes, handouts, imagery/audio presentation and reusable universe assets.
- Quest Portal: linked notes plus optional suggestion workflows for locations, encounters, quests, secrets and strong starts.
- articy:draft: visual narrative database, flow, reusable objects, variables, conditions, dialogue, simulation and structured export.
- Arcweave: flowcharts, components, conditional branches, variables and playtest.
- ink and Yarn Spinner: branching text/dialogue, choices, variables, flow control, tags/commands and portable integration patterns.

## Consolidated capability targets

MAS must provide integrated Adventure assembly from governed Multiversal objects; nonlinear and sandbox structure; CNI-backed conditions and dialogue; clue/revelation planning; session preparation and live reference; timeline/deadline/pressure planning; branch playtest and diagnostics; versioned portable packages; and explicit bindings to canonical owner records without turning preparation into live-state truth.

## Clean-room acceptance

MAS-21 proves those capabilities using original Multiversal content and Multiversal-owned contracts. Exact imitation of any benchmark product is not an acceptance criterion.
