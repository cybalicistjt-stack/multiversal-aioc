# MBES MERA Predecessor Amendment

Status: owner-approved future planning.

MBES now activates after MERA-24 rather than directly after MRCS-21. The affected order is:

MRCS-01..21 → MERA-01..24 → MBES-01..24 → SMB-08

MBES may consume accepted MERA engineering capabilities for machinery, utilities, workshops, garages, shipyards and infrastructure. MBES remains built-environment and settlement orchestration and does not become a second engineering/refit engine.

No current implementation authority is created by this amendment.
