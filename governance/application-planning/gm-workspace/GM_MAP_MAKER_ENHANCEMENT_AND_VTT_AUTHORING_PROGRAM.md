## Product intent and non-negotiable presentation
Create maps and also let GMs place playable source-linked content directly on the **same illustrated Map Maker canvas**: campaign/scene, characters and tokens, creatures/NPCs, traps, hazards, loot, interactables, encounter areas, event triggers, investigation/social entries, environmental cues and multi-level connections. Keep the five-foot grid, fog, lighting, line-of-sight, markers and visibility overlays **on the existing native artwork**, not a separate colored tile/block board. Sources remain searchable/reusable outside active campaigns; Campaign/Scene placement is opt-in. Distinguish local draft → authored Scene reference → GM-reviewed operation → authoritative owner Event; nothing short-circuits permissions, conditions, XP, inventory or combat.
