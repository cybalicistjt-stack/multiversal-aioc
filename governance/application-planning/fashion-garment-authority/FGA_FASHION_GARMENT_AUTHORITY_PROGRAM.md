# FGA — Fashion/Garment Authority

**Program ID:** FGA  
**Version:** 0.1.0  
**Status:** OWNER-APPROVED IMPLEMENTATION EXTENSION; activation remains OPS3 CURRENT-owned  
**Owner/final authority:** John Brandon Turner  
**Primary application repository:** `cybalicistjt-stack/Multiversal-app`

## Purpose

FGA adds deterministic, topology-aware garment construction over the completed Character Appearance stack. It does not create a second Character engine, replace CAS, or turn clothing into equipment/mechanics truth.

Governing flow:

`owner garment/presentation choice → FGA-PARAM-1 garment state → CAS-WARD-001 / MCCS-09 composition → CAPP/PPIA fit + mask + occlusion validation → PAPT reusable garment primitives → CAS-SD1 derivatives`.

## Tranches

1. **FGA-01 — Garment Semantic Vocabulary & Wardrobe Bridge Foundation**  
   Establish FGA-PARAM-1 and bounded presentation-only transport through CAS-WARD-001/MCCS-09/CAPP.
2. **FGA-02 — Topology Fit / Anchor / Occlusion Compilation**  
   Deterministically compile garment state against nonhuman topology, fit anchors, masks, clearance and explicit incompatibility.
3. **FGA-03 — Reusable Garment Primitive & Production-Demand Bridge**  
   Map garment vocabulary to reusable panels/components/material/pattern/mask demand without baked outfit combinatorics.
4. **FGA-04 — Fashion Design Studio Runtime Surface**  
   Player/creator garment editing, layering, fit diagnostics, saved designs and CAS wardrobe composition.
5. **FGA-05 — Clothing Reference → Garment Proposal Adapter**  
   Classify/slice visible clothing evidence into editable FGA-PARAM-1 proposals; never canonical truth.
6. **FGA-06 — Golden Cross-Topology Garment Proof**  
   Prove deterministic garments across ordinary and difficult CAS-GOLDEN-1 topologies and all required views.

## Boundaries

- actual equipment ownership/stats remain outside FGA;
- Species/Form anatomy remains owner truth;
- CAS-WARD-001 stays the wardrobe/outfit bridge;
- Mall/marketplace, commerce, public sharing and inventory storefronts remain separately governed;
- Oaran fashion is a style/content profile layer over FGA, not geometry authority;
- generative image synthesis is not required;
- clothing-reference matching cannot commit without review.
