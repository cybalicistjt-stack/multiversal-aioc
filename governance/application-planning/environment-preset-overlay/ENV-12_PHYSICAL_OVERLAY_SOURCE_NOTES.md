# ENV-12 — Source & Boundary Notes

ENV-12 is grounded in the approved ENV program plus the retained environment framework already cited by ENV-01. That framework explicitly permits environment records to define gravity, atmosphere, pressure, light, radiation, climate/temperature and hazards while keeping participant adaptations, species, equipment, vehicles and powers outside the environment record.

No ENV-12 overlay is presented as recovered source prose. The reusable library is an owner-authorized normalization layer over those established environment domains.

Source-specific values or mechanics remain source-specific. In particular, the retained project corpus contains gravity-shift material, but ENV-12 does not promote its particular die sizes, event timing, saves, multipliers or sample event table into a universal Variable / Directional Gravity rule. Those details remain attached to their actual source/local authority until ENV-14 reconciliation or another separately authorized content pass.

The same rule applies to temperature thresholds, pressure values, oxygen fractions, radiation dose, toxic/corrosive concentrations and illumination levels: ENV-12 provides semantic condition identities and composition deltas, not invented universal numeric standards.
