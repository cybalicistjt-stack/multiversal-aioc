## Scope and provenance boundary

ENV-02 completes the existing forty promoted environment profiles before ENV decomposes them into archetypes, presets, and overlays.

The original profile source text remains immutable. Additions in this file are **ENV-02 authored completions derived from concepts already present in each affected source profile**. They are not recovered PDF text and must never be represented as though they appeared in the original source.

No environment-ability links are added. The twenty-three profiles without source-supported environment-ability links remain unlinked rather than being padded.

For ENV-02, a promoted environment profile is structurally complete when it has substantive coverage for all seven minimum fields:

1. overview;
2. environmental features;
3. movement/navigation;
4. hazards;
5. encounters/challenges;
6. rest/shelter;
7. random encounter table.

### Swamps - Rest and Shelter

*Authored completion derived from the same source profile. No new universal DCs, recovery bonuses, or exhaustion formulas are introduced.*

- **Short Rest:** A short rest is safest on firm, dry, or elevated ground away from deep water, quicksand, and obvious gas vents. Existing leech, Bog Fever, Swamp Rot, predator, and noxious-gas hazards remain applicable if the party rests in exposed or contaminated areas.
- **Long Rest:** A long rest requires a reasonably dry and defensible shelter or camp site. Continue using the profile's existing disease, creature, mud/quicksand, and gas hazards when the camp is poorly chosen or inadequately protected. Open flame near suspected swamp-gas pockets continues to use the profile's existing ignition rule.
- **Shelter:** Useful shelter may come from elevated natural ground, overgrown ruins, or another defensible dry location established in play.

*Authored completion derived from the same source profile. No new universal interruption roll or recovery formula is introduced.*
