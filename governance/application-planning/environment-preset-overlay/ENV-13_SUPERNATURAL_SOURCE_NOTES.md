# ENV-13 — Supernatural Source & Boundary Notes

## Source-backed Chaos/Foam seam

The retained `MV_Master_01_Core.zip` source package contains `02_PDF_Sources/Part 1/Creation/Environment-Based Abilities.PDF`. On **pages 35–36**, it defines a named **Chaos and Foam Environment Perk Tree** with eight published member perks. The recovered CSV index `03_CSV_Sources/Prestige_Env_Abilities.csv` preserves the tree plus its eight member records as `ABL3-00480` through `ABL3-00488`. Those records explicitly key abilities to being in the Chaos or Foam and cover source contexts including thin barriers/planar fractures/foldpoints, shifting geometry, gravity shifts, mutagrowths/residual energy/salvage, memory erosion/identity bleed/echo hallucinations, displacement/time loops, spatial recursion/path mapping, and environmental yes/no information.

The same source package contains `02_PDF_Sources/P3/Worlds/The Chaos v2.PDF`. Pages 1–5 describe the Foam and Chaos as linked remnants of dead realities with inverted/recursive topology, unusual light/gravity, memory/echo phenomena, remnants and non-linear navigation. Later pages include specific travel/time/stability/resource/exposure/adaptation/mutation rules. ENV-13 uses those sources only to establish that **Chaos/Foam is a real environment-dependent context seam**. It does not promote the source-specific XP costs, die sizes, DCs, exposure thresholds, time-conversion ratio, mutation table, or perk mechanics into a universal overlay.

The pending semantic-recovery candidates in `v2/audit-data/...` are corroborating recovery evidence only; ENV-13 does not elevate pending semantic candidates above the retained source PDFs/CSV provenance.
