## Purpose

FDE turns the completed Fashion/Garment Authority into the user-facing Multiversal Fashion Design Engine. It does not reopen or replace FGA-PARAM-1, CAS, MCCS, CAPP/PPIA, PAPT, equipment, anatomy or mechanics authority.

The governing product flow is:

`authorized Creator/Character entry → Fashion Design Studio session → FGA-PARAM-1 garment draft → topology/coverage diagnostics → visible preview → saved design → optional reviewed clothing-reference proposal → CAS-WARD-001 wardrobe proposal`.

The terminal FGA proof established the deterministic garment model. FDE is the productization layer: access, controls, visual presentation, persistence, photo intake orchestration, bounded asset realization and end-to-end usability.

## Tranches

1. **FDE-01 — Live Studio Integration**  
   Put the existing Fashion Design Studio into an authorized real Creator surface; establish product session ownership and wire existing view, history, save/load and wardrobe-proposal actions.
2. **FDE-02 — Designer Controls & Garment Library**  
   Replace callback-only edit affordances with real selectors/sliders/swatches/layer editors and a governed garment-family/material/pattern/trim/palette catalog.
3. **FDE-03 — Visual Garment Preview**  
   Connect FGA garment state to the appearance/rendering stack so edits visibly render across body types/species and full-body/portrait/token views.
4. **FDE-04 — Persistent Designs & Collections**  
   Durable My Designs storage, reopen/duplicate/variant/version workflows, collections and governed import/export.
5. **FDE-05 — Clothing Photo Intake**  
   User image upload/capture → garment detection/region slicing/visible-feature analysis → FGA-05 review-gated proposals → editable Studio draft. Hidden details are never invented.
6. **FDE-06 — Primitive / Asset Realization**  
   Route explicit FGA-03 missing-coverage demand into governed asset-production capability; no silent paid-provider execution or authority widening.
7. **FDE-07 — Product Golden Proof**  
   End-to-end user proof: enter Studio, design from scratch, design from a clothing reference, fit difficult topologies, save/reopen, preview and compose wardrobe without authority leakage.
