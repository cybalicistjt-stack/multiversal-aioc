## Locked owner decision

Orange/Ember and Chromatic are both active potential Multiversal color schemes. They are equal candidate theme packs over the same structural UI system; neither is currently the selected default.

Future implementation must not choose between them by assumption. The convergence handoff requires matched-layout owner review across representative hero, gameplay, map/graph, dense utility, authoring, and administration surfaces before the final palette gate closes.

## Critical design-authority rule

Current Internal Alpha React screens, synthetic-fixture pages, and cyan-biased alpha CSS are implementation evidence and behavioral test surfaces. They are **not** final visual-design authority.

Future UI work must use this authority order:

1. explicit owner-approved visual/design decisions and the UI convergence package;
2. governed UI Design Bible and Screen Design Bible requirements/refinements;
3. approved mockups/reference-image lineage;
4. current implementation, evaluated against the above.

This rule does not weaken current implementation authority for behavior, data, permissions, validation, provenance, session/action/combat ownership, audit, recovery, or AI governance.

## Behavioral preservation rule

UI convergence is presentation/composition work over existing governed systems. It must preserve:

- permission and control boundaries;
- server/current-authority filtering of hidden information before client delivery;
- provenance/source visibility;
- exact-version validation and immutable launch binding;
- proposal/approval authority;
- AI advisory/proposal-only behavior;
- audit/version history;
- offline/recovery constraints;
- semantic Scene/Combat meaning independent of mere pixel position.

No presentation schema may become a competing source of gameplay truth.

1. the relevant convergence section and implementation handoff;
2. the corresponding UI Design Bible tranche(s);
3. corresponding Screen Design Bible screen IDs/refinements;
4. owning behavioral contracts/code;

Unrelated historical material remains blocked unless a conflict or missing authority requires escalation.
