## Purpose

CAPP advances the already-completed PPIA-06 Character Appearance Creator from implementation-ready architecture into production-ready customization content, compatibility data, deterministic tooling, renderer asset specifications, UX state contracts, export rules, migration behavior and large-scale QA assets that can be completed before application runtime work is available.

CAPP is additive. It does not reopen PPIA-06 or revise its completed evidence. PPIA-06 remains the canonical appearance architecture/design authority. PPIA-05 remains Species/Form/current-body/persistent/live biology authority. PPIA-03 remains actual Asset ownership/equipment/install-state authority.

CAPP may create authored production-preparation data, synthetic/noncanonical fixtures, compatibility matrices, tooling contracts, deterministic reference tools and implementation handoffs. It must preserve provenance classes and may not invent source-backed biological facts where source authority is absent.

## Non-activation boundary

CAPP does not activate or complete STAGE-A-A2, application runtime, deployment, release, tester access, paid services, production credentials, unsupported canonical-content promotion, Design Standards exact-byte ingestion, or WP-011 / Apple work.

A valid Character remains valid when a renderer lacks coverage. Appearance never grants mechanics, changes actual equipment, creates anatomy, selects unavailable Forms, erases persistent biology, or leaks hidden information.

## Work program

### CAPP-01 — 25-Species Appearance Choice Registry + Constraint Model

Convert all 25 governed Species/Form profiles into machine-readable customization choices with stable IDs, provenance, semantic layer, biological/cosmetic/presentation/read-only classification, Species/Form eligibility, compatibility conditions, renderer requirements, visibility/permission behavior and explicit unknown/unavailable handling.

Define executable dependency/constraint rules for conditional controls, mutually exclusive choices, required anatomy, derived profiles, form/season transitions, topology-specific anchors and compatibility consequences.

This work item is the foundation for all later CAPP work.

### CAPP-02 — Preset, Randomization and Lock Libraries

Build eligible choice pools, weighting/coherence rules, deterministic seed behavior, category/randomize-all/randomize-unlocked recipes, lock semantics, portable presets and synthetic reference presets for all Species and special profile cases.

### CAPP-03 — Pixel-Art Asset Production Standard

Translate `pixel-art-v1` into a production asset specification covering canvas classes, semantic bands, anchor-coordinate conventions, masks, palette ramps/zones, topology templates, safe areas, view variants, stable asset metadata, directory/package layout and acceptance criteria.

### CAPP-04 — Asset Manifest and Coverage Analyzer Contract

Define the production asset registry and coverage model that reports supported/partial/unsupported/unknown coverage by Species, topology, semantic choice, pose, view, wardrobe/equipment fit and asset-pack version without invalidating Character state.

### CAPP-05 — Deterministic Appearance Compiler / Reference Engine

Build a repository-side reference tool that accepts authorized semantic appearance state plus biological snapshots, renderer/version, asset lock, pose/view and permission projection and emits a deterministic semantic render-plan JSON with assets, layers, anchors, masks, palette zones, occlusion, diagnostics and fallback state.

This is a reference/validation tool, not application runtime.

### CAPP-06 — Wardrobe and Equipment-Fit Compatibility Catalog

Define presentation-wardrobe fit classes and actual-equipment visual projection compatibility across humanoid, large, small, four-arm, six-limb, winged, tailed, unusual-head, nested-appendage, aquatic, insectoid, plant, composite and other governed topologies. No fit rule may imply inventory ownership or mechanics.

### CAPP-07 — Full Appearance Studio Screen and State Specification

Convert the existing Appearance Studio control surface into implementation-grade screen states, control types, progressive disclosure, desktop/tablet/mobile composition, keyboard/focus order, screen-reader semantics, high-zoom/reduced-motion behavior, dirty/preview/commit/revert/undo behavior and empty/error/partial-renderer/recovery states.

### CAPP-08 — Portrait, Token and Export Production Contract

Define portrait framing, tactical-token framing, safe regions, transparent/background outputs, derivative identity/versioning, permission-safe export metadata, stale derivative invalidation/regeneration and downstream handoff behavior.

### CAPP-09 — Appearance Versioning and Migration Engine Contract

Define deterministic behavior for removed/renamed options, schema upgrades, asset-pack upgrades, renderer capability changes, missing packs, old presets, partially recoverable imports and compatibility re-evaluation without silent substitution.

### CAPP-10 — Accessibility Description Grammar

Define and test structured nonvisual appearance descriptions for body topology, surface, coloration, distinguishing features, wardrobe, equipment projection, renderer support and change announcements while preserving hidden-information filtering.

### CAPP-11 — Expanded Generated QA and Coverage Corpus

Generate large deterministic compatibility/regression matrices over Species, topology, forms/seasons/transitions, presets, randomization locks, hidden information, renderer gaps, equipment fit, asset/version migration, mobile, keyboard and accessibility behavior. Generated cases remain synthetic/noncanonical unless independently source-backed.

### CAPP-12 — Integrated Production Handoff and Completion Gate

Integrate CAPP-01 through CAPP-11 into one implementation handoff with exact traceability to PPIA-06/PPIA-05/PPIA-03 authorities, zero unintended orphaned choice/constraint/renderer/UX coverage, deterministic validators, hosted CI, completion report and signed/verified merge evidence.

## Dependency-optimized execution order

`CAPP-01 → CAPP-02 → CAPP-03 → CAPP-04 → CAPP-05 → CAPP-06 → CAPP-07 → CAPP-08 → CAPP-09 → CAPP-10 → CAPP-11 → CAPP-12`
