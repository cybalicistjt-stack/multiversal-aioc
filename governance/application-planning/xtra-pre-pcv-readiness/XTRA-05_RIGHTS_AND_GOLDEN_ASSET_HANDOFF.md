## Provenance and licensing decisions

1. **Separate content canon from media rights.** A source-owned `PPIA/D28/MRCS` Definition with object ID/version is a valid governed reference; it is not evidence that some portrait, sound, sprite, font, third-party map, or AI-generated derivative has an ARI-cleared `campaign-use` or `redistribution` capability.
2. **Apply existing ARI-11, not a new rights authority.** The merged app ARI-11 evaluator records `private-use`, `transform`, `campaign-use`, `export`, `redistribution` and `commercial-use` separately. Unknown/denied/revoked do not grant those capabilities. GPR-10 consumes these states for production selection, export and distributable projection; the source fixture provides no per-placement ARI media matrix or byte hash.
3. **Use the open-source catalog as discovery only.** OCS-01 lists 38 source providers across tiers A–D and says item-level origin, author, license/terms, acquisition date, checksum, attribution and downstream constraints must be verified. No library-wide search result, CC badge, public domain assumption, modified asset or marketplace listing grants a per-item clearance.
4. **OARC terminal readiness has different meaning.** OARC-07 reconciled 6,708 *operational Definition* source rows, 42 game-ready (0.626%), 1,079 normalization-needed, 5,587 waiting existing owner, and 6/6 representative operational-asset goldens. It did not license Beacon Debt NPC portraits or certify the actual installed PCV-10 two-human audiovisual path.
5. **No automatic redistribution.** Every one of the 34 placement rows has an explicit object ID/version/owning domain and a fail-closed media-rights disposition. Unknown `campaign-use`, `export`, `redistribution` and `commercial-use` are **not approved**, not assertions that the authored storyline itself is prohibited. Actual asset-rights decisions belong to ARI/owning providers, not XTRA.

## Source-authored nonvisual alternative versus an unresolved placeholder

The A5 fixture's five gridless map/scene alternatives are **intentional described semantic locations**, not missing-path placeholders. They can be legitimate inputs to a text/accessible presentation. However the XTRA-05 source read did not run the Android or Windows UI, keyboard/screen-reader parity, current GPR/ARI live selection or real two-human play; those remain unverified.

An accidental blank never becomes acceptable simply because a source fixture has a description.

## Required evidence before individual media clearance

- Canonical ARI resource ID and exact source owner, URL/provider ID, acquisition or creation provenance, file SHA-256, and upstream author/owner.
- Exact per-item license and terms version/date, attribution/share-alike/restrictions, any trademark/likeness/privacy constraints, and current permitted-use capabilities for campaign, transform, export, redistribution and commercial use.
- For generated output: all primary source IDs, upstream rights, generator/recipe version, versioned derivative lineage and reviewer evidence.
- For a procedural or intentionally text-only alternative: named asset-demand row, owning UI/scene use case, accessible Android/Windows semantic parity test and approved fallback decision.
- For protected subscriber/user-created assets: real owner rights, campaign provenance and one-allowance/dependency enforcement from PCV-03F; do not treat a source asset grant as permission to move derivatives cross-campaign.

**Decision rule:** absent that evidence, keep `unknown` and block commercial/export/redistributable media, while preserving the approved game's source definitions and independent future work.
