# ISE provider/reference notes

This note records planning context only; implementation must reverify current provider capabilities, APIs, SDKs, licenses, entitlement rules and supported import formats at MAI-01/AAI-01 and again when an adapter is selected.

Owner-approved planning assumes that Multiversal should take advantage of legitimate structured map/scene imports (including UVTT-class metadata where supported), user-owned map/tileset/token assets, and provider-controlled audio through capability-driven adapters. Provider examples such as Czepeku, Syrinscape and TableTone are targets for capability evaluation, not hard-coded canonical dependencies.

No commercial media redistribution, scraping, unsupported API emulation or entitlement bypass is authorized by ISE planning.
