## Governing interpretation

The source expresses the intended experience: loot acquisition, environmental scavenging, item/object decomposition, component recovery, condition/quality variation, mechanical repair and reuse of recovered parts.

It is **not** a direct implementation specification. Existing Multiversal systems (D17 Asset Instances, MIB-03 deterministic runtime, MIB-12 crafting/repair, MIB-13 economy, MIB-14 vehicle/base/component compatibility, APW Projects and ICF creature harvest) supersede local source mechanics where they overlap.

No source formula, rarity rule, skill list, component list, die table or quality conversion becomes canonical merely because it appears in the source. LSS-01 must reconcile each such rule before implementation.
