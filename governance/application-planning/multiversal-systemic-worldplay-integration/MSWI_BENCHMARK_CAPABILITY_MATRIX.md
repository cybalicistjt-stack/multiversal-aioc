# MSWI Benchmark Capability Matrix

**Program:** MSWI — Multiversal Systemic Worldplay Integration  
**Research date:** 2026-09-15  
**Status:** planning provenance / clean-room capability study

## Rule

The benchmark titles below are used only to identify generalized product capabilities and design lessons. Their protected code, content, maps, audiovisual assets, formulas, distinctive UI expression, save formats and private protocols are not implementation dependencies and are not to be copied.

## Deduplication decisions

The study originally suggested several capabilities that already exist or are already planned in stronger Multiversal form. They are **not** being reopened as new MSWI owner domains:

- Profession/activity framework → already implemented by DPL profession activity profiles.
- Enterprise/staffing/growth → already implemented by DPL-08 and DPL-14 integration.
- Arts/performance foundations → already implemented by DPL-10; MSWI adds only diegetic timing/cue integration.
- Cybernetics/symbiotes/biotech augmentation → already implemented by DPL-13; MSWI adds donor-aware embodied-modification composition.
- Creature ecology/habitat/lifecycle/population generation → already planned in MNCS-12/17/20; MSWI adds campaign-time systemic consequence routing and world transformation coupling.
- Generic gameplay loop execution/composition → already planned in GPR; MSWI composes cross-domain systemic loops over it.
- Engineering/refit/asset modification → MERA.
- Built environment, utility networks, logistics, production chains and settlement development → MBES.
- Adventure/scene assembly → MAS.
- Map geometry and cartographic authoring → MCS.

## Net-new or materially deeper MSWI capability set

1. Persistent player-driven world-transformation state and threshold propagation.
2. Lightweight ecology succession and attributable population consequences coupled to changing world state.
3. Composite multi-role entity binding without duplicate canonical identity.
4. Creature anatomy/component harvesting tied to damage, quality and provenance.
5. Donor-aware embodied modification integrated with identity/form/state.
6. Campaign-scoped doctrine/ideology progression with obligations and consequences.
7. Cross-owner profession/enterprise/life orchestration rather than new profession/business ledgers.
8. Reusable pursuit/race/chase/convoy/interception scenes across movement modes.
9. Diegetic performance/timing cues with mandatory accessible equivalents.
10. Grand/world projects that aggregate contributions and produce staged visible world consequences.
11. Seeded procedural site/scenario remix with ephemeral/proposed/persistent promotion states.
12. Environment-state map/scene variants preserving one stable location identity.
13. Transformation campaign templates that configure rather than fork the runtime.
14. Interaction-density diagnostics measuring justified cross-system responsiveness and missing routes.

## Design invariant extracted from the study

The family is successful when Multiversal does not merely have many adjacent systems, but makes meaningful actions produce justified, attributable responses across those systems while preserving owner authority, provenance, determinism where declared, visibility boundaries and GM/owner control.
