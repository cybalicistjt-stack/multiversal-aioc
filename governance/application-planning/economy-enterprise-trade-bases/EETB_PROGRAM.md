## Cycle contract
Every cycle produces a new numbered self-contained offline HTML file, retaining all previous working functionality; source register, change log, cumulative regression checks, owner review scenario and known limitations. Test actual interactions where possible; report browser proof vs static/unit evidence honestly. No external hosting, production writes, real money or new product authority. Use deterministic fixtures and explicit world-time, player proposals and GM decisions; financial values contextual. Protect against duplicated assets/currency, stale prices, hidden information leaks, unlimited supply and free wall-clock gains. Arbitrage is a desirable gameplay path, not categorically an exploit; distinguish accessible profitable trade from risk-free engine errors. Every cycle has a discrete endpoint; Continue advances exactly one tester cycle after preceding review unless user redirects.
