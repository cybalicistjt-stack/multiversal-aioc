## Core result

The tranche establishes scaling as source-bounded role/composition/presentation guidance rather than permission to manufacture stronger stat blocks. Kits can emphasize existing strengths, expose counterplay, change positioning, shift timing/cadence, redistribute governed composition, or soften failure/exit pressure.

Every kit requires exact source capabilities. Missing support returns `not_applicable`. Unsupported powers, actions, reactions, resistances, immunities, weaknesses, phases, resources, statistics, relationships, lore, or canon are prohibited. Numeric adjustment is permitted only when the owning source explicitly authorizes the exact parameter and range.
