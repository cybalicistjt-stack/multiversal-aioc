# CASI — Character Appearance Standard Integration

**Program ID:** CASI  
**Version:** 0.1.0  
**Status:** OWNER-APPROVED IMPLEMENTATION EXTENSION; activation remains OPS3 CURRENT-owned  
**Owner/final authority:** John Brandon Turner  
**Primary application repository:** `cybalicistjt-stack/Multiversal-app`

## Purpose

CASI integrates the owner-approved CAS-SD1 pixel standard and CAS-PARAM-1 semantic appearance vocabulary into the already completed MCCS/CAPP/PAPT architecture. It does not reopen completed MCCS or OARC history and does not create a second Character Appearance engine.

Governing flow:

`owner Character/Species/Form/Equipment truth → CAS-PARAM-1 → MCCS workspace → CAPP deterministic compilation → PAPT reusable assets → CAS-SD1 outputs`.

## Tranches

1. **CASI-01 — Semantic Appearance Parameter Transport Foundation**  
   Implement the stable CAS parameter registry/runtime state validator and bounded MCCS transport adapters, including detailed head/face scalar transport adjacent to completed MCCS-05.
2. **CASI-02 — CAPP Deterministic Parameter Resolution**  
   Extend the application-side CAPP seam to resolve CAS parameters to deterministic component/variant/palette/mask receipts with explicit coverage.
3. **CASI-03 — CAS-SD1 Renderer / Derivative Profiles**  
   Bind 128×160, 96×96, 64×64 and Retrobit semantic derivative profiles with native/output metadata and loss declarations.
4. **CASI-04 — PAPT Coverage & Production-Demand Bridge**  
   Emit reusable component-family production demand and coverage diagnostics without baked-character combinatorial growth.
5. **CASI-05 — Golden Reusable Appearance Pack Foundation**  
   Establish governed fixtures/components sufficient for the approved CAS-GOLDEN-1 topology suite.
6. **CASI-06 — Character Appearance Studio Runtime Surface**  
   Wire player-facing CAS editing to completed MCCS workspace semantics and deterministic preview.
7. **CASI-07 — Reference Image → CAS Proposal Adapter**  
   Add bounded photo/reference matching that proposes supported CAS state and never becomes renderer truth.
8. **CASI-08 — Golden Cross-Topology Integration Proof**  
   Prove deterministic manual/reference-input paths, full-body/portrait/token/Retrobit consistency, authority separation and provider-off operation.

Fashion/garment construction is downstream of the deterministic CAS golden proof and remains separately governed.

## Cross-cutting invariants

- completed MCCS/CAPP/PPIA authority is consumed, not rewritten;
- CAS semantic state uses stable IDs and bounded values, not unconstrained 3D sliders;
- no silent humanoid fallback or nearest-supported semantic coercion;
- no Character mechanics, biology or equipment-ownership mutation through appearance;
- core rendering remains deterministic and does not require generative AI;
- missing visual coverage remains explicit;
- blocking workflows remain local/provider-off capable.
