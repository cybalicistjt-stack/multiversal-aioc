# CAB-16 — Completion Report

CAB-16 sets Campaign pacing targets at 250 / 500 / 750 / 1,000 XP per substantive session for Slow / Standard / Fast / Accelerated profiles, with Standard as CAB's normal reference. These are long-run pacing targets, not automatic payouts.

It retains the 1,300-XP normal start pending CAB-21 final simulation, keeps learning time separate from XP earning, permits XP banking, and rejects a universal catch-up multiplier.

**Exact successor:** CAB-17 — XP Award Framework.
