# CAB-20 — Owner-Delegated Decisions

**Program:** CAB — Character Advancement & Balance  
**Date:** 2026-09-05  
**Authority:** standing owner recommendation delegation recorded in `CAB-08_OWNER_DECISIONS_2026-09-05.md`

CAB-20 introduced no material conflict with prior owner authority, no unrelated implementation/release authority, and no owner-specific creative choice. The following integrated recommendations are therefore adopted.

## CAB-Q20-01 — Integrated balance architecture

**Decision: adopted.**

Use the CAB-20 integrated architecture as the authoritative CAB model: XP controls acquisition speed; prerequisites and acquisition rules control coherent eligibility/development; tiers control depth; action economy, resources, stacking, dependencies and high-risk review control simultaneous impact.

## CAB-Q20-02 — No scalar collapse

**Decision: adopted.**

Do not add a universal Character Level, CR analogue, weighted power score, Ability-count cap, readied-Ability slot system or global diminishing-return price simply to summarize or constrain advancement.

## CAB-Q20-03 — Numeric anchors

**Decision: adopted.**

Carry forward the current CAB numeric anchors as the working integrated rules for CAB-21 simulation: 1 CU = 250 XP; 1,300 normal starting XP; direct Ability reference bands 250/500/1,000/2,000/4,000/8,000+ XP; ordinary progression access 1,000/500/1,250/2,500/5,000 XP as defined in CAB-06; CAB-10 Attribute/Skill/Knowledge/Proficiency schedules; Standard pacing 500 XP per substantive session; CAB-17 award bands 0/250/500/750/1,000 XP.

CAB-21 may recommend a pacing/start calibration change only if its simulation evidence requires it.

## CAB-Q20-04 — Corpus uncertainty

**Decision: adopted.**

The integrated rules are valid even though the 4,816-record corpus still contains content-level identity, timing, acquisition, interaction, pricing and source-boundary repair needs. Missing/legacy fields are not silently treated as balanced or implementation-ready.

## CAB-Q20-05 — Migration posture

**Decision: adopted.**

CAB-19 nonpunitive correction/migration semantics remain part of the integrated model. Later repair/repricing cannot create retroactive XP debt for a previously valid Character solely because the new calibrated price is higher.

## Successor

CAB-20 is resolved under the standing delegation. **CAB-21 — Reference Character & Campaign Simulation** is selected next.
