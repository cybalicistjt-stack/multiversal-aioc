# CAB-11 — Audit Decisions

**Authority:** standing CAB recommendation delegation.

Adopted:

1. `Record_ID` is treated as source-file scoped until a governed globally unique stable ID exists; source-qualified identity is mandatory for repair/migration because 1,256 ID values collide across files.
2. Sparse/missing fields are triaged by semantic need, not filled automatically.
3. Missing purchase/timing/prerequisite/interaction semantics remain unresolved where consequential rather than being inferred from tier, dataset, name, or price.
4. Headers, collections, source listings, grants, and explicitly non-applicable rows are not forced into purchasable-Ability schemas.
5. Statistical repair taxonomy: identity namespace, purchase semantics, runtime timing, prerequisite semantics, interaction semantics, intentional source absence, provenance-only source gap.
6. No individual Ability reprice/rewrite is authorized by CAB-11 alone.

No standing-delegation guardrail triggered.
