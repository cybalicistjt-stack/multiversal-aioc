## CAB-Q02-01 — Should ordinary assets ever use Character XP as their purchase/upkeep currency?

**Decision impact:** HIGH  
**CAB recommendation:** **C**.

A. Yes. XP may function as a general currency for Character improvements, transferable equipment, vehicles, drones, refits and upkeep when a source says so.

B. No. XP may only ever purchase Character-internal capabilities; every asset cost must be credits/resources.

C. **Recommended:** ordinary transferable assets, equipment, vehicles, drones, refits and upkeep use their owning credits/resources/economy. XP may be used only where the purchased thing is itself a permanent Character-bound progression feature or an explicitly exceptional advancement sacrifice.

D. Unsure; preserve the conflict until later CAB analysis.

**Reasoning:** recovered drone rules spend thousands of XP on acquisition and recurring XP on upkeep. If ordinary equipment competes directly with permanent advancement, campaign wealth/assets and character power become entangled. Option C preserves room for genuinely character-bound evolving companions/forms/artifacts without making XP the mundane economy.

## CAB-Q02-02 — Should percentage modifiers to XP gain exist as an ordinary progression mechanic?

**Decision impact:** MEDIUM-HIGH  
**CAB recommendation:** **A**.

A. **Recommended:** no ordinary percentage XP multipliers. Training/facilities may affect eligibility, training time, practice, or provide a bounded explicit award, but do not multiply all XP earned.

B. Allow percentage XP bonuses only from rare/high-tier abilities or facilities.

C. Allow percentage XP bonuses generally where content provides them.

D. Unsure; defer to CAB-16/CAB-17.

**Reasoning:** a recovered ship facility grants +10% XP during downtime. Percentage multipliers compound over long campaigns and can make two otherwise equal characters diverge merely because one gained access to an economic asset. That is difficult to balance against fixed XP prices.

## CAB-Q02-03 — How should existing hazard/trap XP values be treated?

**Decision impact:** MEDIUM  
**CAB recommendation:** **B**.

A. Treat published/source XP tags as automatic payouts whenever the hazard/trap is overcome.

B. **Recommended:** retain them as source benchmark/reference values, but let CAB-17 determine the actual award method so avoiding, surviving, disabling, negotiating around, or otherwise resolving a challenge can be rewarded according to accomplishment rather than mechanical kill/defeat tags alone.

C. Remove encounter-object XP tags entirely and award XP only at session/adventure milestones.

D. Unsure; defer to CAB-17.

**Reasoning:** the source corpus contains a clear 100/250/500-style hazard reward pattern, but PPIA-11 deliberately rejects a single universal challenge scalar. Reference values can remain useful without becoming an automatic universal payout table.

## CAB-Q02-04 — At Character creation, should XP and money/equipment budgets be convertible?

**Decision impact:** HIGH FOR CAB-03  
**CAB recommendation:** **A**.

A. **Recommended:** keep advancement XP and creation wealth/equipment budgets separate; no ordinary XP-to-credits conversion.

B. Allow one-way XP -> credits conversion during Character creation only.

C. Allow bidirectional conversion during Character creation.

D. Preserve a source-defined conversion only for specific Campaign/rules profiles, not as the Multiversal default.

E. Unsure; CAB-03 should reconstruct the competing creation baselines first and return with a narrower recommendation.

**Reasoning:** separating permanent advancement from equipment wealth makes equal-XP Character comparisons meaningful and avoids making mundane equipment an opportunity cost against permanent capabilities. Option D is a viable alternative if a specific setting/profile genuinely uses a point-buy creation pool across both categories.
