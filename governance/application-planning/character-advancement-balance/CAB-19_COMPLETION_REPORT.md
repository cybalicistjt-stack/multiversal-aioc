# CAB-19 — Completion Report

CAB-19 separates voluntary respec, nonpunitive correction/errata, and one-time CAB legacy migration. Permitted voluntary respec returns 100% of actual paid XP, while free grants/RAV refund zero. Availability/downtime controls abuse rather than refund penalties.

Price increases create no retroactive debt. CAB migration credits proven legacy overpayment but grandfathers valid historical underpayment instead of driving a Character negative. Dependency cascades, source-qualified identity, before/after evidence and append-only receipts are mandatory.

**Exact successor:** CAB-20 — Integrated Advancement Balance Model.
