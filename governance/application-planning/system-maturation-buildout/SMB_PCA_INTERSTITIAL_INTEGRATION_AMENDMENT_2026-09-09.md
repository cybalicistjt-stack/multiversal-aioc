`SMB-01 → SMB-02 → SMB-03 → SMB-04 → SMB-05 → SMB-06 → SMB-07 → CNI-01..13 → PCA-01..16 → SMB-08 → SMB-09 → SAA-01..20 → SMB-10 → SMB-11 → SMB-12 → SMB-13 → SMB-14 → SMB-15 → SMB-16 → BRP-01..11 → SMB-17 → SMB-18`

This supersedes the earlier direct `CNI-13 → SMB-08` handoff. CNI's content/narrative responsibilities are unchanged; PCA is a production-acceleration layer over existing owners.

## SMB-08 dependency effect

SMB-08 — Core Content Production must now consume, where applicable:

- PCA reusable production recipes and caches;
- PCA procedural environment/material/character derivative pipelines;
- PCA motion, audio/voice and style-locked generation workflows;
- PCA visual authoring over CNI;
- PCA simulation/balance evidence;
- PCA localization-preparation state;
- PCA asset-production governance and internal QA evidence.

SMB-08 remains the owner of substantial first-party content production. PCA produces tools/candidates/derivatives and does not become first-party canon/content authority.

## Existing owner boundaries

ARI, SSA, CAPP, AAI, DWC, CNI, APM, SMB-11/12/13/16 and BRP retain the boundaries stated in the PCA program. No PCA tool may bypass those owners simply because it accelerates production.
