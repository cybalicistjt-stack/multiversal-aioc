# Constraint and Rationale Reasoning

This governed Development Brain layer converts explicit active constraints, validated Design Intent Memory, and validated Decision and Tradeoff History into evidence-backed advisory reasoning records.

## Required behavior

- Explicit source constraints outrank derived conclusions.
- Rationale chains may use only explicit rationale and directly linked governed records.
- Conflicts, unmet prerequisites, circular chains, stale inputs, missing evidence, and unresolved gaps remain visible.
- Every record preserves authority, confidence, freshness, evidence, and derivation method.
- Unsupported conclusions are omitted rather than guessed.

## Authority boundary

This layer cannot execute, mutate, approve, promote, certify, assign, schedule, supersede, reconcile, or enforce source content. Repository review, CI, and owner/governance approval remain required.
