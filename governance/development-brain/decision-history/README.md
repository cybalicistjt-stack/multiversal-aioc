# Decision and Tradeoff History

This governed derived layer preserves explicit decision chronology and documented tradeoffs from Project Memory and validated Design Intent Memory.

## Included

- stable decision identities and source-memory links;
- active, superseded, rejected, deferred, and unresolved statuses;
- chronology, rationale, alternatives, tradeoffs, consequences, authority, confidence, and evidence;
- supersession links;
- diagnostics for conflicts, duplicates, stale records, missing rationale, and broken supersession.

## Boundaries

The generator does not infer decisions, alternatives, tradeoffs, or consequences from names, implementation shape, lexical similarity, code structure, or AI preference. Missing information remains empty or diagnostic. This artifact is advisory and cannot create, reverse, approve, supersede, enforce, promote, certify, assign, or schedule work.
