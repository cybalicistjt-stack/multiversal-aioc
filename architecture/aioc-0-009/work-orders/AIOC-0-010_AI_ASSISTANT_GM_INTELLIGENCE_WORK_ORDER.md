# Work Order — AIOC-0-010
## AI Assistant and GM Intelligence Architecture

## Objective

Define the AIOC architecture for conversational project command, GM intelligence, bounded recommendations, evidence-backed answers, action proposals, context assembly, permissions, memory, explainability, uncertainty, escalation, and cross-repository execution.

## Required Inputs

- AIOC-0-001 through AIOC-0-009;
- Multiversal AI Systems specifications;
- GM workflows and gameplay authority model;
- repository continuity and provenance standards;
- campaign, runtime, communication, notification, and moderation contracts.

## Required Deliverables

1. Full implementation-ready architecture specification.
2. AI assistant capability catalog.
3. GM intelligence capability catalog.
4. Governed workflow catalog.
5. Validation-rule catalog.
6. Conversation, context packet, recommendation, action proposal, evidence citation, and escalation schemas.
7. Permission and authority matrix.
8. Memory and context-retention model.
9. Explainability, uncertainty, and provenance requirements.
10. Acceptance and integration test matrix.
11. Validation result.
12. Outgoing AIOC-0-011 work order.

## Mandatory Constraints

- AI advice never becomes authoritative state by itself.
- AI actions invoke governed commands and approvals.
- Hidden information is filtered before context assembly.
- Responses identify evidence, assumptions, and uncertainty.
- GM assistance cannot grant owner authority or override player agency.
- Project intelligence must distinguish repository fact, inferred state, and recommendation.
- Memory must be repository-grounded and revocable.
- Provider-specific features cannot become architectural dependencies.
