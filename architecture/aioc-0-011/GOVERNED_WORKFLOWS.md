# Governed Workflows

1. Identity enrollment: request → verify → approve → activate → audit.
2. Session establishment: authenticate → assess assurance → issue session → monitor → expire.
3. Permission change: propose → impact-check → owner approval → apply → verify → audit.
4. Privileged repository mutation: bind repo/path/SHA → authorize → approve → execute → verify.
5. Secret registration: create external secret → register reference → scope → test → activate.
6. Secret access: request purpose → authorize → issue temporary access → use → revoke → audit.
7. Secret rotation: create replacement → dual validation → switch reference → revoke old → verify.
8. Suspected leak: detect → quarantine → revoke → rotate → investigate → close.
9. Release candidate: freeze inputs → build → hash → test → evidence packet.
10. Release approval: evaluate gates → approve exact candidate → publish → monitor.
11. Release rollback: detect trigger → authorize → restore prior candidate → verify → incident review.
12. Protected-branch exception: propose → owner approval → temporary exception → execute → restore protection.
13. Break-glass access: declare incident → narrow scope → authorize → activate with expiry → review.
14. Security incident: classify → contain → preserve evidence → remediate → validate → retrospective.
15. Agent credential use: dispatch purpose → least-privilege token → execute bounded task → revoke.
16. Cross-repository action: identify target → confirm policy → bind exact change → approve → execute.
17. Audit export: authorize → redact → package → hash → deliver → record access.
18. Governance certification: collect controls → run tests → resolve failures → owner sign-off → publish.
